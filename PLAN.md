# План: клон Atari Asteroids

Игра на Unity 2020.3. Цель — довести недописанный клон до играбельного состояния с механикой оригинала 1979.

Ветка: `cursor/asteroids-original-mechanics-32fa`
PR: https://github.com/trickingegg/Asteroids/pull/1

---

## Сделано

### Ядро оригинала
- [x] Астероиды трёх размеров, раскол большой → 2 средних → 2 малых
- [x] Очки 20 / 50 / 100
- [x] Пули-частицы сбивают все размеры (средний/малый раньше были trigger — Particle System их не видел)
- [x] Инерция корабля без торможения при отпускании газа
- [x] Wrap через край экрана: корабль, камни, пули, тарелки
- [x] Волны: 4, 6, 8, дальше 10 больших с краёв
- [x] 3 жизни, респаун в центре с неуязвимостью, +1 жизнь за 10 000
- [x] Hyperspace (`Left Shift` / `H` / `S` / `↓`), ~25% смерть при выходе
- [x] Тарелки: большая 200, малая 1000 (малая после 40 000)

### Поток сцен и UI
- [x] MainMenu → Новая игра → Game
- [x] Пауза Esc, оверлей больше не висит при старте
- [x] Выход из паузы / Game Over → главное меню (не Quit приложения)
- [x] Сброс `Time.timeScale`, очков, жизней и пула при смене сцены
- [x] Переключатель клавиатура / мышь (единственная настройка), пишется в PlayerPrefs

### Тесты правил
- [x] `Assets/Tests/Editor/GameRulesTests.cs` (NUnit в Unity)
- [x] `python3 Tools/verify_game_rules.py`

## Намеренно не как в оригинале

- Корабль **не замедляется** сам — так было задумано (космо-инерция).
- Камни **не толкаются** друг с другом — как в оригинале.
- «Продолжить» в главном меню серое: сейва нет.

## Дальше, по приоритету

### 1. Прогнать в Unity (обязательно, ещё не делали)
Открыть проект в **Unity 2020.3.18f1**, сыграть одну сессию:
- большой колется на два средних, средние на два малых, пули бьют все три;
- wrap корабля и пуль;
- меню → игра → пауза → выход в меню → новая игра;
- Game Over и «Новая игра».

Без этого остальное гадание.

### 2. Идентичность оригинала (самое заметное, чего нет)
- [ ] «Сердцебиение» / thump, которое ускоряется, когда камней мало — это звук Asteroids
- [ ] Сирена тарелки (разная у большой и малой)
- [ ] Разные взрывы для большого/среднего/малого камня и корабля
- [ ] Звук extra life
- [ ] Таблица рекордов и ввод инициалов после Game Over
- [ ] Надпись GAME OVER, а не просто пауза без «Продолжить»

### 3. Добетон механики, если после плейтеста ок
- [ ] Hyperspace: в оригинале шанс смерти растёт, когда экран забит камнями
- [ ] Малая тарелка целится с учётом wrap (стреляет «через край»)
- [ ] Лимит ~27 камней на экране, как в аркаде
- [ ] Не спавнить волну поверх корабля, если он стоит у края

### 4. UI / настройки, которых не хватает
- [ ] Либо спрятать «Продолжить» в главном меню, либо сделать сейв
- [ ] Громкость (хотя бы master), если появятся сирена и heartbeat
- [ ] Подсказка управления на паузе (сейчас только переключатель схемы)

### 5. Уборка, когда геймплей стабилен
- [ ] Мёртвый код: `Bonds.cs`, `PlayerInitialize.cs`, `PrefabRefs.cs`, старый `Pool.cs`, `AsteroidSpawnMiddle.cs`, пустой `AsteroidMovementBig.cs`, неиспользуемый `ShipMovementMouse.cs`
- [ ] Тарелка — это сплющенный спрайт астероида, не тарелка
- [ ] Камни — круги, не векторные «скалы»

### 6. Вне скоупа, пока не попросим
- Онлайн-таблица, мобильное управление, рескин под CRT/вектор, смена движка

## Что брать следующим шагом

**Сыграть в редакторе Unity.** Дальше по ощущению от плейтеста:

1. Если раскол/пули/меню ещё врут — чинить это, не полировать.
2. Если ядро держится — heartbeat + сирена тарелки. Без них клон «играется», но не звучит как Asteroids.
3. Потом рекорды и нормальный Game Over.

Не начинать рескин и чистку скриптов, пока не пройдена живая сессия в редакторе.
